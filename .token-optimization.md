# Token Optimization Strategy

Practical rules for keeping Agentic SDLC context small, relevant, and traceable.

## Context Compression

- Summarize Jira responses into: story key, title, acceptance criteria, constraints, dependencies, risks, and open questions.
- Pass links and decision summaries instead of repeating complete prior artifacts.
- Read only the current stage artifact and the minimum approved predecessor context.
- Preserve exact evidence references, approval status, and unresolved blockers when compressing.

## Prompt Reuse

- Reuse stable CREATE rules, stage contracts, artifact paths, tool guidance, and approval gates from `.cache/prompt-cache.md`.
- Send only changing values such as `<JIRA_STORY>`, approved artifact paths, decisions, and validation results.
- Do not cache story details, credentials, approvals, test output, or other volatile data.
- Refresh shared prompts only when the pipeline contract or repository conventions change.

## Agent Handover Summary

Every handover should contain only:

```text
Story: <story-id> and title
Stage: <completed stage>
Status: approved | rejected | blocked
Artifact: <path>
Decision: <approver, rationale, timestamp>
Evidence: <links, tests, or validation results>
Risks: <unresolved risks or none>
Next action: <exact action and owner>
```

A later agent must not start without an explicit `approved` status and the required predecessor artifact.

## Dynamic Context Loading

- Load context just before use rather than placing all pipeline stages in every prompt.
- Requirements: load Jira data and repository conventions.
- Architecture: load approved requirements and relevant integration constraints.
- Design review: load approved requirements, architecture, and review criteria.
- Verification: load approved code review, implementation evidence, acceptance criteria, and validation results.
- Exclude unrelated files, completed stage transcripts, duplicate instructions, and stale rejected artifacts.
- Stop loading additional context once the stage objective and evidence requirements are satisfied.
